# 五格剖象法算法说明

"五格剖象法"（又称熊崎氏姓名学，因日本学者熊崎健翁整理传入而得名）依据姓名笔画数，
按固定公式算出天格、人格、地格、外格、总格五个数字，再查 81 数吉凶表与三才五行生克关系，
作为传统文化中解读姓名的一种参考方法。

## 一、五格计算公式

设姓氏为 X1（复姓再加 X2），名字为 M1（双字名再加 M2）：

| 姓名字数组合 | 天格 | 人格 | 地格 | 外格 | 总格 |
|---|---|---|---|---|---|
| 单姓单名（如"李明"） | X1+1 | X1+M1 | M1+1 | 2（固定） | X1+M1 |
| 单姓双名（如"李文博"） | X1+1 | X1+M1 | M1+M2 | M2+1 | X1+M1+M2 |
| 复姓单名（如"欧阳明"） | X1+X2 | X2+M1 | M1+1 | X1+1 | X1+X2+M1 |
| 复姓双名（如"欧阳文博"） | X1+X2 | X2+M1 | M1+M2 | X1+M2 | X1+X2+M1+M2 |

五格含义（传统解读的大致落点，不绝对化）：

- **天格**：代表祖上、长辈的荫庇，一般不作为个人运势主要参考（由姓氏笔画机械推得，非本人可改变）
- **人格**（又称"主运"）：代表本人性格、才能、婚姻与中年运势，是五格中最重要的一格
- **地格**（又称"前运"）：代表青少年运势、家庭基础、与子女晚辈的关系
- **外格**：代表社交、外在人际关系、以及"副运"
- **总格**（又称"后运"）：代表中年以后、晚年的整体运势走向

## 二、数值折算与查表

1. 若某一格数值超过 81，按公式 `((n - 1) % 81) + 1` 折算到 1-81 区间内再查 81 数吉凶表
   （81 是"数理之数"的循环终点，超过后被认为回到 1 重新循环）
2. 五行取该数值的**个位数**（10 按 0 处理）：
   - 1、2 → 木
   - 3、4 → 火
   - 5、6 → 土
   - 7、8 → 金
   - 9、0 → 水
3. 查 `references/81-shuli.md` 得该数字的吉凶等级（大吉/吉/半吉半凶/凶/大凶）与简短释义

## 三、三才五行生克

"三才"指天格、人格、地格三格的五行组合（如"木木火"），传统上认为三才配置比单看某一格数理更能体现整体格局是否顺畅。本方法只给出通用的五行生克判断规则，不逐一穷举 125 种（5×5×5）具体组合的吉凶表：

- **天格 → 人格**：判断天格五行与人格五行的关系
- **人格 → 地格**：判断人格五行与地格五行的关系

五行相生顺序：木生火 → 火生土 → 土生金 → 金生水 → 水生木
五行相克顺序：木克土 → 土克水 → 水克火 → 火克金 → 金克木

两格五行之间只会是以下三种关系之一：
- **相生**：其中一方五行生另一方（如天格属火、人格属土，"火生土"，一般视为顺畅、有助力）
- **相克**：其中一方五行克另一方（如天格属木、人格属土，"木克土"，一般视为有摩擦、需留意磨合）
- **比和**：两格五行相同（如都属木，力量集中但也可能偏执、缺乏调和）

**重要**：相生相克本身只是描述一种能量流动关系，不等同于绝对的"好"与"坏"——相生也可能过度（如一方一味生助另一方导致自身耗损），相克也未必全然不利（如财官相制反而有成）。具体解读仍需结合各格数理吉凶与命主实际情况，避免机械化下结论。

## 四、重要提醒：笔画必须用康熙字典繁体笔画

**五格剖象法的笔画数，规定使用《康熙字典》中该字的繁体（正体）笔画数，不是简体笔画数，也不是日常书写时数的笔画数。** 这一点是姓名学计算中最容易出错、也最容易被忽略的地方。以下是几个常见误区：

- **三点水"氵"**：简体书写数是 3 画，但康熙字典按其本字"水"部计算，算作 **4 画**。同类的还有提手旁"扌"（简体数 3 画，康熙按"手"部算 **4 画**）、左耳旁"阝"作"阜"部时算 **8 画**、右耳旁"阝"作"邑"部时算 **7 画**。
- **草字头"艹"**：这是姓名学界公认的争议点之一。有的流派按《康熙字典》原始归部算 **6 画**（艸部本身即 6 画），也有流派按民间通行简化算法算 **3 或 4 画**。不同的姓名学软件、不同的师承对此常有不同处理，**没有唯一公认的标准答案**，使用前需与具体咨询的师傅或工具确认其采用的口径。
- **示补旁"礻"、衣补旁"衤"**：容易混淆。"礻"按"示"部算 **5 画**，"衤"按"衣"部算 **6 画**，两者字形相似但笔画数不同，手写时很容易数错或搞反。
- **简体字与繁体字笔画数完全不同的常见字**：例如"从"简体 4 画，繁体"從"11 画；"义"简体 3 画，繁体"義"13 画；"卫"简体 3 画，繁体"衛"15 画。如果用户直接报简体笔画数代入计算，结果会完全错误。

**因此，脚本本身不做简繁转换、不做部首归类、不查字典——所有笔画数必须由用户/调用方预先查证后作为数字直接输入。** 遇到用户报不上来准确笔画数时，应引导其：

1. 使用手机输入法自带的"部首检字"或"笔画查询"功能，切换到繁体查看
2. 查阅纸质或电子版《康熙字典》
3. 使用专门的姓名测试网站或软件（多数会自动按康熙笔画计算五格）
4. 如果确实无法确认，如实告知用户"以下按你提供的笔画数计算，若笔画数有误，结果也会相应有误"，不要替用户猜测或编造笔画数
