# 六亲、用神与旺衰分析参考

六爻断卦的核心思路是"以所问之事找用神，以用神的旺衰、生克、动静来判断吉凶
趋势"。本文档整理六亲判定口诀、六亲对应问事类型的选用神原则，以及旺衰判断
的基本框架，供分析阶段（第三阶段）使用。旺衰判断需要结合具体日期、具体问事
灵活判断，不适合写成脚本里的机械规则，因此单独整理在这里，由你在分析时结合
`scripts/qigua.py` 的输出灵活运用。

## 一、六亲判定口诀

六亲（父母、兄弟、子孙、妻财、官鬼）由"本卦所属宫的五行"与"该爻纳甲地支
的五行"比较生克关系而定，以宫五行为"我"：

> 生我者为父母，我生者为子孙，克我者为官鬼，我克者为妻财，同我者为兄弟。

`scripts/qigua.py` 已经按此口诀自动算出每一爻的六亲，分析时直接引用脚本
输出即可，不需要重新推算。

## 二、六亲对应的问事类型（选用神的第一步）

六爻分析和八字不同：**六爻必须先明确问的是什么事，再确定用神**，同一个卦
问不同的事，用神（该看哪一个六亲）完全不同。下表是常见问事与对应六亲用神
的基本对应关系，实际取用时还要结合具体问法进一步细化：

| 六亲 | 常见对应问事 |
|---|---|
| 父母 | 长辈、父母、师长；文书、合同、证件、学业、房屋（作为庇护物时）；辛劳操心之事 |
| 兄弟 | 兄弟姐妹、同辈、朋友、合伙人、同事；破财、争夺、竞争对手 |
| 子孙 | 子女、晚辈、学生；福德、医药、消灾解难；忌讳官运（子孙克官鬼） |
| 妻财 | 财运、钱财；男命的妻子、女友；日常消费、货物 |
| 官鬼 | 官运、职位、工作、考试功名；疾病、灾祸、诉讼；女命的丈夫、男友 |

**用神选取的基本原则**：
1. 先明确所问之事属于哪一类，再从上表找对应六亲，在卦中找到该六亲所在
   的爻，即为"用神爻"。
2. 若卦中同一六亲出现在多个爻位（比如两个妻财爻），一般优先取**世爻附近**
   或**动爻**、**临值日/月建**的那一个作为用神；若用神与世爻同一爻（世爻
   本身就是用神），则直接看世爻旺衰。
3. 若卦中所问六亲**不上卦**（六个爻里没有出现该六亲），需要用"伏神"
   （该六亲本应纳的地支，隐伏于对应爻位之下，需查本宫首卦对应位置）来看，
   这部分较为专门，涉及不确定信息时应提醒用户这是间接推断，不要臆造伏神
   的具体旺衰结论。
4. 世爻代表求测人自身或所问之事的主体一方，应爻代表对方或所问之事的对应
   面（如问合作看对方是否配合、问姻缘看对方态度）。问自身相关的事（如
   自己的运势、自己的病）通常以世爻为参考核心之一，但不能替代按问事类型
   选出的专门用神。

## 三、旺衰判断的基本框架

用神选定后，要判断这个爻"旺"还是"衰"，才能进一步谈吉凶趋势。旺衰不是
孤立看某个爻的五行，而要结合**日建**（起卦当日的日干支）、**月建**
（起卦当月的月支，若用户只给到"日"，可只看日建，月建判断需知道起卦月份）
对用神的生克冲合关系，从以下几个角度综合考虑：

### 1. 日建、月建对用神的作用（"旺相休囚死"的简化判断角度）

- **生**：日建或月建的五行生用神爻的五行 → 用神得"生扶"，偏旺。
- **克**：日建或月建的五行克用神爻的五行 → 用神受"克制"，偏衰，但仍要看
  用神自身是否当令（下面第2点）。
- **同**：日建或月建与用神爻同五行（比肩） → 用神得"帮扶"，偏旺。
- **冲**：日建或月建的地支与用神爻地支"六冲"（子午冲、丑未冲、寅申冲、
  卯酉冲、辰戌冲、巳亥冲）→ 视具体情况可能是"暗动"（原本安静的爻被日冲
  而变得活跃，需关注）也可能是"冲散"（原本要发生的事被打断），需结合
  用神是动是静综合判断，不要一概而论为凶。
- **合**：日建或月建的地支与用神爻地支"六合"（子丑合、寅亥合、卯戌合、
  辰酉合、巳申合、午未合）→ 多主牵绊、拖延、合而不动，或有人事上的
  牵绊撮合，吉凶需结合所问之事判断（问姻缘遇合多主好事，问诉讼遇合可能
  拖沓不决）。

### 2. 用神自身是否当令、当季（不依赖日建/月建时的基础旺衰）

- 用神的五行如果与起卦当月的月令五行相同或被月令所生，属于"当令"或
  "当生"，本身根基较旺。
- 若信息不足以精确判断月令（比如只有起卦日期没有精确到节气），可以
  只用日建生克作为主要参考，向用户说明"因未精确到节气，旺衰判断以日建
  为主，月建仅供参考"。

### 3. 动爻对用神的生克（卦中动爻的影响）

- 卦中若有其他爻发动（动爻），要看这个动爻的五行对用神爻是生是克：
  动爻生用神，用神更旺；动爻克用神，用神受伤，需留意所问之事的阻力。
- 用神自身若是动爻，要看变卦（该爻变化后的新纳甲五行）对本卦用神爻是
  "回头生"（变卦五行生本卦用神原来的五行，主渐入佳境）还是"回头克"
  （变卦五行克本卦用神原来的五行，主先顺后阻或自我耗损），这是判断
  动爻趋势的重要角度。
- 用神临应爻或被应爻所克，也要留意"对方/环境因素对所问之事的制约"。

### 4. 综合判断，给出趋势性解读

- 六爻断卦传统上追求给出较明确的吉凶判断，但作为文化研究与参考工具，
  应避免给出绝对化、恐吓性的断语，措辞上使用"偏旺""偏弱""趋势上更有利于
  ……""需留意……方面的阻力"等中性表达，而不是"必成""必败""大凶"。
- 涉及健康、法律、财务的具体判断，必须提醒用户以专业医生、律师、理财
  顾问的意见为准，六爻分析仅作传统文化视角下的参考。

## 四、几种常见边界情况的分析角度

- **六爻全静（无动爻）**：说明当前事态相对静止、尚未进入明显变化的阶段，
  分析重心应放在**世应关系**（世应是否相生相合、是否相冲相克）和**用神
  本身的旺衰**上，而不强行寻找"动爻趋势"。可以提示用户"目前是静观其变的
  阶段"。
- **动爻较多（4条及以上）**：动爻越多，卦局变化越复杂，传统上有"多动看
  变卦""以世应所临之爻为主"等取舍思路，可优先关注：① 世爻或用神爻本身
  是否为动爻（若是，优先看它的变化）；② 多个动爻之间是否有生克链条
  （比如某动爻克用神，另一动爻又生用神，需要综合抵消判断，不要只挑一条
  动爻下结论）。分析时应明确告知用户"动爻较多，卦象变化复杂，以下解读
  为几种趋势中相对占优的一种，仅供参考"。
- **用神爻与忌讳爻（如问官运时的子孙爻）同时发动**：说明该问事存在明显
  的制约因素，如实告知用户这个制约的传统含义，同时说明这只是传统命理
  角度的参考，具体决策仍需结合现实情况。
