# 六爻参考典籍

| 典籍 | 作者/年代 | 地位 |
|------|-----------|------|
| 《京氏易传》 | 西汉·京房 | 纳甲筮法的源头，以乾坤坎离统摄六十四卦，本方法的纳甲装卦规则即源于此 |
| 《火珠林》 | 相传宋初·麻衣道者 | 现存最早的纳甲筮法专著，提出"卦定根源，六亲为主"，标志纳甲六爻占法正式成形 |
| 《黄金策》 | 相传明代·刘伯温（托名，实际作者已不可考） | 火珠林卦法的集大成之作，是六爻筮法体系化、规范化的重要著作 |
| 《卜筮正宗》 | 清代·王洪绪 | 对《黄金策》的重要注解本，体例清晰，后世学六爻常以此入门 |
| 《增删卜易》 | 清代·野鹤老人 | 对卦爻生克制化、旬空月破等基本规则的论述极为精详，是六爻理论集大成之作 |

## 引用规范

- 分析用神旺衰、生克冲合时，可引用《增删卜易》《卜筮正宗》里对应的论断口诀（如有把握），并标注出处
- 六亲、纳甲、世应等确定性规则以 `methods/liuyao/references/najia-guize.md` 为准，与本文件不冲突——本文件提供的是理论渊源和引用来源，具体计算规则以脚本和 najia-guize.md 为准
- 不确定某条断语具体出自哪部典籍时，用"传统六爻理论认为……"这类泛称，不要编造引句或凭空归属到某部典籍名下
